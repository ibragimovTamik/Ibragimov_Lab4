# Лабораторная работа №4

Тема: оптимизация проекта и разработка модульных тестов.

Проект основан на системе управления заказами из предыдущих лабораторных работ. Для лабораторной №4 создана отдельная копия репозитория: исходный проект не изменяется.

## Что выполнено

- сохранена многослойная структура C#/.NET 8;
- сервисы используют интерфейсы репозиториев, что позволяет подменять зависимости;
- добавлены модульные тесты xUnit с mock-объектами Moq;
- проверены ветви с корректными данными, пустым заказом, отсутствующим товаром, дубликатом логина и ошибками валидации;
- целевой слой `OrderManagement.Application.Services` покрыт на 100% по строкам и ветвям: 60/60 строк и 22/22 ветви;
- добавлен GitHub Actions workflow для сборки и запуска тестов при каждом push и pull request;
- исходное приложение не переписано с нуля: выполнено расширение тестами и рефакторингом поверх структуры предыдущей работы.

## Запуск в Visual Studio

1. Открыть `OrderManagement.sln`.
2. Дождаться автоматического восстановления NuGet-пакетов.
3. Открыть меню `Тест` и выбрать `Запустить все тесты`.
4. Для покрытия использовать `dotnet test` с файлом `coverage.runsettings` или сбор диагностических данных покрытия в Visual Studio.

Дополнительно вручную устанавливать ничего не нужно: пакеты xUnit, Moq и Coverlet указаны в проекте и восстанавливаются NuGet.
